# 選択ナビ(仮)

ユニクロ・GU の服を、素材と素材の特性(吸湿性・保温性・シワになりにくさなど)で横断して探し、比べるための非公式サイトです。

- 各ブランドとは無関係の非公式サイトです。商品名・画像・価格の権利は各社に帰属します。
- 価格・在庫はデータ取得時点のものです。購入前に必ず公式サイトで確認してください。
- 素材の特性は、繊維の一般的な性質と混率から計算した目安です。

## しくみ
- `scraper/scrape.py`: 公式サイトの商品情報を収集(1.5秒に1回・同時接続なし)。画像は保存せず URL のみ扱う
- `scraper/build_data.py`: 素材表記を解析して `site/data.js` を作る
- `tools/check_data.py`: 品質チェック。合格した時だけ公開を更新する
- `.github/workflows/pages.yml`: 毎週月曜に上の3つを実行し、GitHub Pages に公開

## 手元で見る
```
python -m http.server 8765 --directory site
```
